Comandos de tarefas — chats e worktrees **reais** do harness pelo bot. Quatro comandos novos no núcleo neutro da superfície (`worker/surface/**`), iguais em qualquer provedor: `/novo-chat <prompt>` e `/novo-chat-wt <worktree> <prompt>` abrem **sessões reais do DSH** com o prompt submetido (confirmação em 2 etapas; prompt saneado para uma linha e cortado em 4096 — o que se confirma é o que corre; o `<worktree>` do `/novo-chat-wt` tem de já existir, criado pelo `/worktree`); `/worktree <nome> [base]` cria uma **worktree git** `guard/<nome>` em `<repo>-worktrees/<nome>` a partir de `base` (default `HEAD`) sem nunca destruir o que exista (`WORKTREE_ALREADY_EXISTS` → `noop`); `/status-tarefa <id>` mostra o detalhe de UM run com as **métricas reais** do harness (12 campos — session-stats para contagens/tempos, `TokenUsage` dos eventos para tokens; campo não medido = `—`, nunca estimado). `/agentes` passa a listar agentes, **chats e worktrees** com métrica resumida (`kind`, `wt: <nome>`, `📊 <tokens> / <tempo>`). Os comandos novos entram no texto de `/ajuda`; `COMANDOS_PUBLICADOS` continua `/menu`, `/parear`, `/ajuda` (TG-080). Manual: `docs/AGENTS.md` §4b; textos exatos: `docs/ux/01-CONTRATO-BOT.md` §11.
